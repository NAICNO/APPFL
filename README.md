# APPFL

## APPFL: Advanced Privacy-Preserving Federated Learning

APPFL is an open-source, highly extensible framework that makes it easy and safe to run real federated learning (FL) experiments across distributed clients, helping you train more robust ML models. This repository documents the implementation details and testing workflows at the University of Oslo.
